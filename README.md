## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ahamedbafan786-png/ai-practical.git
   cd ai-practical
   ```

2. **Set up a virtual environment (optional but recommended):**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install jupyter pandas scikit-learn numpy matplotlib
   ```

4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
